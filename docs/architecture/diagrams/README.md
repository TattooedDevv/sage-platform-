## Public-information boundary

These diagrams intentionally omit private IP addresses, VPN ranges, physical hostnames, account names, storage endpoints, credentials, private keys, firewall source rules, and other operational details. They use generic roles and logical relationships only.

Some components are planned architecture, not claims that every service is currently implemented. Refer to each diagram's status note and the project roadmap before treating a component as deployed.

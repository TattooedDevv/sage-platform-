# Sage Platform

Sage is a long-term, self-hosted AI knowledge platform designed to grow with the information, workflows, and engineering capabilities I choose to develop. The project combines AI engineering with hands-on platform engineering and systems design.

## Architecture documentation

Explore the [public architecture diagrams](./docs/architecture/diagrams/README.md) for high-level views of Sage's system context, automatic model routing with manual override, Sage Council and Sage Quant, memory and knowledge flows, and logical homelab topology.

These diagrams describe the intended architecture and logical component relationships. They deliberately omit private infrastructure addresses, credentials, VPN details, host-specific access rules, and other operationally sensitive information. Planned components are not necessarily implemented yet; consult each diagram's notes for scope and status.
